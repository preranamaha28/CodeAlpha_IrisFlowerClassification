# CodeAlpha - Iris Flower Classification

## Project Overview
This project uses Machine Learning to classify Iris flower species based on sepal and petal measurements.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-Learn

## Machine Learning Algorithm
Decision Tree Classifier

## How to Run

1. Install required libraries:

pip install -r requirements.txt

2. Run the project:

python iris_flower_classification.py

## Results
The model achieves approximately 95% to 100% accuracy.
